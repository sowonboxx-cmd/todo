# Ultimate Dashboard

Application en un seul fichier (`index.html`) + Supabase, publiée sur GitHub Pages.

**Avant toute modification, lire et suivre [`DESIGN.md`](DESIGN.md)** : charte graphique,
composants à réutiliser et règles de travail (ne jamais changer l'existant sans demande,
pas de contrôles natifs du navigateur, pas d'emojis, maquettes avant les gros changements).

- Ne jamais committer de données privées (courses, recettes, SQL avec données) dans ce dépôt public.
- Les migrations SQL vont dans `supabase/` (schéma seulement).
